\subsection{Giải thích}
\begin{itemize}
  \item Theo định luật Ohm:
  \[ I_B = \frac{V_{BB}-V_{BE}}{R_1} = \frac{5\,\text{V} - 0.7\,\text{V}}{1\,\text{k}\Omega} = 4.3\,\text{mA} \]
  \item Giả sử BJT ở vùng tích cực:
  \[ I_C = \beta I_B = 100 \times 4.3\,\text{mA} = 430\,\text{mA} \]
  \item Kiểm tra giả thiết:
  \[ V_{CE} = V_{CC} - I_C R_2 = 10\,\text{V} - 430\,\text{mA}\times 100\,\Omega = 10 - 43 = -33\,\text{V} \]
\end{itemize}
Vì $V_{CE} = -33\,\text{V} < $ $V_{CE(sat)}$ = 0.65V, giả thiết vùng tích cực là sai. BJT ở \textbf{vùng bão hòa}, khi đó $V_{CE} = V_{CE(sat)} = 0.65\,\text{V}$ và $I_C$ do mạch ngoài ($V_{CC}$, $R_2$) quyết định, không còn bằng $\beta I_B$:
\[ I_C = \frac{V_{CC} - V_{CE(sat)}}{R_2} = \frac{10\,\text{V} - 0.65\,\text{V}}{100\,\Omega} = 93.5\,\text{mA} \]
Kiểm tra: $I_C = 93.5\,\text{mA} < \beta I_B = 430\,\text{mA}$, tức $I_B$ dư để đẩy BJT vào bão hòa (hệ số bão hòa $\beta_{forced} = I_C/I_B \approx 21.7 < \beta$).

\begin{dapsobox}
$I_B = 4.3\,\text{mA}$ \qquad $I_C = 93.5\,\text{mA}$ \qquad $V_{CE} = 0.65\,\text{V}$
\end{dapsobox}
