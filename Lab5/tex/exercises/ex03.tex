\section{Summing Amplifier}\label{sec:summing}

\subsection{Non-inverting summing}\label{sec:summing-a}
\given{fig5_06}{0.5\linewidth}{Non inverse summing using OPAMP\label{fig:5-06}}

\subsubsection*{Tính toán lý thuyết}
KCL tại nút $V_{IN}$ (dòng vào ngõ $(+)$ bằng $0$):
\[
\frac{V_1 - V_{IN}}{R_1} + \frac{V_2 - V_{IN}}{R_2} + \frac{V_3 - V_{IN}}{R_3} = 0
\;\Rightarrow\;
V_{IN} = \frac{V_1/R_1 + V_2/R_2 + V_3/R_3}{1/R_1 + 1/R_2 + 1/R_3}
= \frac{2.6}{1.7} \approx 1.529\,\text{V}.
\]
Mạch khuếch đại không đảo:
\[
V_{OUT} = \Bigl(1 + \frac{R_f}{R_i}\Bigr) V_{IN} = 10 \times 1.529 \approx 15.29\,\text{V}.
\]
Lưu ý: với nguồn cấp mặc định $\pm 15\,\text{V}$ của \texttt{OPAMP}, ngõ ra bị kẹp ở $15\,\text{V}$ (bão hòa); vì vậy mô phỏng đặt \texttt{VPOS} $=20\,\text{V}$ để thấy đúng $15.29\,\text{V}$.

\begin{dapsobox}
$V_{IN} \approx 1.529\,\text{V}$, \quad $V_{OUT} \approx 15.29\,\text{V}$.
\end{dapsobox}

\subsection{Inverting summing \bonus}\label{sec:summing-b}
\given{fig5_07}{0.45\linewidth}{Inverse summing using OPAMP\label{fig:5-07}}

\subsubsection*{Tính toán lý thuyết}
Đất ảo $V_{(-)} = V_{(+)} = 0$; KCL tại nút $(-)$:
\[
\frac{V_{i1}}{R_1} + \frac{V_{i2}}{R_2} + \frac{V_o}{R_3} = 0
\;\Rightarrow\;
V_o = -\Bigl(\frac{R_3}{R_1}V_{i1} + \frac{R_3}{R_2}V_{i2}\Bigr)
= -(10 \times 1 + 5 \times 5) = -35\,\text{V}.
\]
Lưu ý: $|V_o| = 35\,\text{V}$ vượt nguồn mặc định $\pm 15\,\text{V}$, ngõ ra sẽ bị kẹp ở $-15\,\text{V}$; vì vậy mô phỏng đặt \texttt{VPOS}/\texttt{VNEG} $=\pm 40\,\text{V}$ để thấy đúng $-35\,\text{V}$.

\begin{dapsobox}
$V_o = -35\,\text{V}$.
\end{dapsobox}
